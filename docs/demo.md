# Сценарій захисту

1. За 45 секунд пояснити карту контейнерів і ролі.
2. Увійти як dispatch-west, вибрати Тягач 07 й показати живі координати та графік.
3. Перемкнути тиждень і зберегти CSV. Обрати Фургон 08 та пояснити «Немає GPS».
4. Показати список і деталі Flutter. Перевірити межі форми та оновлення ETag.
5. Відкрити протоколи тестів і Compose. Пояснити 200 → 503 → 200.

Запасні матеріали: скриншоти дашборду, клієнта, вивід тестів і JSON запуску Compose.
