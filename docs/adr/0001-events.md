# ADR 1. Socket.IO та SSE

Статус: прийнято для навчального стенда.

Контекст: диспетчерська панель отримує позицію близько 1 Гц.
Для 50 автомобілів опитування кожної машини раз на секунду дає 50 HTTP-запитів за секунду на один екран.
Спільний REST-запит міг би зменшити цю цифру, але надсилав би незмінені поля та вимагав власного відновлення.

Рішення: Socket.IO для панелі, окремі кімнати регіонів, REST для історії.
SSE використано в окремій лабораторній вправі для одностороннього потоку з Last-Event-ID.
Рендер позиції обмежено одним таймером на секунду.

Наслідок: сервер тримає довгі з’єднання.
Проксі передає Upgrade і не буферизує SSE.
Після reconnect панель повторно читає останні значення через REST.
Доказ: fleet/test/integration.test.js.
