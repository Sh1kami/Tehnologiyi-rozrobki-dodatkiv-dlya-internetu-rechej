# ADR 3. Доступ водія до свого ТЗ

Статус: прийнято для навчального стенда.

Контекст: GPS-трек може розкривати маршрут водія.
Рішення лише на фронтенді залишило б API без перевірки.

Варіант A: однакова видимість усіх ТЗ для автентифікованих.
Варіант B: сервер зв’язує sub з ідентифікатором автомобіля та роллю.

Рішення: B. JWT перевіряється за алгоритмом, issuer, audience й exp.
Роль перевіряється проти реєстру, а ідентифікатор ТЗ береться з призначення в SQLite.
Диспетчер читає парк через REST, а потік отримує для свого регіону.
Прострочений токен закриває довгі підключення.

Наслідок: для масштабування слід спільно зберігати сесії та ліміти входу.
Доказ: 401 без токена, 403 для іншого ТЗ, 200 для призначеного ТЗ.
