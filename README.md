# Fleet Watch · Технології розробки додатків для інтернету речей

Панчишкін Богдан Олександрович · **3ПРс/3** · **№19, домен №4 «Транспортний парк»**

Наскрізний проєкт: MQTT → SQLite → REST, Socket.IO та SSE. React-панель диспетчера і Flutter-клієнт використовують той самий API. Телеметрія синтетична.

## Локальний запуск

Потрібен Node.js 22.13+. Із кореня:

    cd fleet
    npm ci
    npm run build
    npm run demo

Відкрийте http://127.0.0.1:3080 і увійдіть як dispatch-west з паролем Fleet-local-demo-19. Ці дані діють у локальному demo. Для Compose створіть власний .env за [інструкцією](DEPLOY.md).
